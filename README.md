# Projeto-de-Integração 1

Tema do projeto:
Desenvolvimento de uma plataforma web interativa vinculada ao projeto de extensão InteliGente, voltada ao letramento em Inteligência Artificial para professores. A plataforma terá como proposta organizar a formação por meio de micro-módulos de aprendizagem, permitindo que os professores desenvolvam seus conhecimentos gradualmente de acordo com o tempo disponível, com acompanhamento do progresso e emissão de certificados de conclusão.
